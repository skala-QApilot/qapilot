# 지시사항

위 컨텍스트와 입력 데이터를 기반으로 테스트 실패의 근본 원인을 분석하라.

## 추론 단계
1. 증상 확인: summary와 mismatches는 무엇이 잘못됐는지 알려준다. expected_behavior는 테스트가 기대한 정상 동작(명세된 규칙)이니, 실제 관측과 대조해 무슨 규칙이 어겨졌는지 파악하라.
2. 원인 추론: 이 증상이 왜 발생했는지 코드 컨텍스트에서 단서를 찾아라.
   - 어떤 함수/엔드포인트에서 이 데이터를 처리하는가?
   - 트랜잭션, 상태 업데이트, 검증 로직 중 어디가 문제인가?
3. cause 작성: "X 함수에서 Y 처리가 누락/잘못되어 Z 증상이 발생했다" 형태로 써라.

## 출력 규칙
- 원인 후보를 1~3개 도출하고 rank를 부여하라.
- 각 후보에 대해 근거(evidence)를 포함하라. 근거 없으면 confidence를 0.3 이하로 설정하라.
- evidences.type은 "code_location" 또는 "runtime_data" 만 사용하라.
- JSON만 반환하라.
